# 발표 자료 구성안

## 1. 문제

- 창업지원 공고는 조건과 제출 사항이 길고 여러 기관에 흩어져 있습니다.
- 근거가 없는 추천은 실제 신청 판단에 위험을 줄 수 있습니다.

## 2. 해결 방식

- PDF와 웹 공고를 하나의 검색 인덱스로 구성
- BM25와 벡터 검색을 RRF로 결합
- 지역·단계·나이 조건을 fail-closed 방식으로 적용
- 근거가 약하면 답변하지 않고 원문 출처를 코드로 생성

## 3. 데모

1. 웹 자료 수집 및 인덱스 재구축
2. “만 39세 서울 예비창업자” 질의
3. 적용된 필터와 리랭커 점수 확인
4. 답변의 문서 번호와 원문 출처 대조
5. 근거가 없는 조건으로 안전한 답변 거부 시연

## 4. 검증

- 단위 테스트와 GitHub Actions CI
- 통합 평가의 통과율·인용률·거부율
- 향후 정답 데이터셋 기반 Recall@K 및 인용 정확도 측정

## 5. 한계

- 웹사이트 구조 변경에 따른 수집 실패 가능성
- 규칙 기반 자격 메타데이터 추출의 한계
- 경량 리랭커의 의미 이해 한계
- 실제 신청 전 원문 공고 확인 필요
